# Предрегистрация: HOUR_1 momentum+low-vol на 5 фьючерсах (2026-11-02)

**Статус:** зафиксировано **ДО** прогона. После чисел параметры не меняются.

**Зачем (шаг C):** дневной портфель momentum+low-vol (`docs/42`) дал
dev PF **1,781** (block p=0,0135) и OOS PF **1,384** на 161 сделке, но
block p=0,0875 — **INCONCLUSIVE** из-за мощности. HOUR_1-версия того же
сигнала даёт в ~5 раз больше сделок на тех же 5 инструментах и использует
**новые данные** (17 824 + 17 818 + 17 072 + 14 393 + 12 965 баров), не
участвовавшие в дневном тесте. Проверяется, сохраняется ли edge при
внутридневном горизонте.

> Pre-screen вне движка. PASS — повод для formal engine-валидации (шаг A),
> не для LIVE.

## 2. Сигнал

- `mom = close(i)/close(i−20) − 1` (20 часов).
- `ATR20% = ATR20/close`; `volPct` — перцентиль за 252 часа.
- Торгуем только при `volPct ≤ 0,50` (low-vol).
- Вход на открытии следующего часа; выход через 5 часов; одна позиция на
  инструмент, без пирамидинга; сигналы во время удержания игнорируются.
- Warmup: 270 часов; до этого сигналов нет.

## 3. Статистика

Блочный bootstrap по **датам выхода** (блок = все сделки, закрывшиеся в этот
день, по всем инструментам), 2 000 итераций, seed 42. Дополнительно — наивный
p по сделкам.

   запрещены.

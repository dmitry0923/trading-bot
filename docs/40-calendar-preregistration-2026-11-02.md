# Предрегистрация: календарные/налоговые эффекты CNYRUBF (2026-11-02)

**Статус:** зафиксировано **ДО** прогона. После чисел параметры не меняются.

**Зачем:** после capacity gate (`maxC 2–4` разрешён) и трёх неудачных
технических классов (ORB, carry, сессии, дневной momentum) проверяется
**независимый класс — календарные/потоковые эффекты**. Экономическая
мотивация: в РФ налоговый период — последняя неделя месяца; экспортёры
продают валюту для уплаты налогов, рубль укрепляется, **CNY/RUB падает**.
Гипотеза: short CNYRUBF в последние 5 торговых дней месяца имеет
положительный edge. Контроли — обратная сторона и turn-of-month.

> Pre-screen вне движка; PASS — только повод реализовать в движке и прогнать
> formal WFA.

(новый горизонт, не использованный ранее).

## 2. Варианты (ровно 5, без сетки)

Календарные ранги считаются по **торговым дням месяца** (не календарным).

| ID | Название | Окно входа | Направление | Выход |
|---|---|---|---|---|
| **C1** | `tax_short` | 5-й торговый день до конца месяца | SHORT | закрытие последнего дня месяца |
| **C2** | `tax_long` | тот же | LONG | тот же |
| **C3** | `tom_long` | последние 2 или первые 2 торговых дня месяца | LONG | следующее закрытие (1 день) |
| **C4** | `tom_short` | тот же | SHORT | следующее закрытие |
| **C5** | `friday_short` | пятница | SHORT | закрытие пятницы |

- C1/C2: вход на открытии следующего дня после сигнального (5-й день до
  конца), выход по закрытию последнего дня месяца. Если в месяце < 5 торговых
  дней — пропуск.
- C3/C4: каждый день окна — отдельная сделка (1 день); перекрытия нет.
- C5: вход на открытии пятницы, выход по закрытию пятницы.
- C1/C2 — основная гипотеза (налоговый поток); C3–C5 — контроли/плацебо.

## 3. Издержки и funding

- Комиссия 3 ₽/сделку; slippage 1 bp на входе и выходе.
- Funding: для каждой даты, где позиция пересекает клиринг 18:45,
  `funding_history[date]` (`long` платит `+r`, `short` получает `−r`).

## 4. Гейты

### 4.1 Dev

| # | Гейт | Порог |
|---|---|---|
| D1 | Сделок | **≥ 30** |
| D2 | Profit Factor | **≥ 1,30** |
| D3 | P(noEdge) (bootstrap 2 000, seed 42) | **< 0,05** |
| D4 | Средний net | **> 0** |

Если проходят несколько — максимальный PF; донастройка запрещена. Если ни
один — класс закрывается `REJECTED`, OOS не запускается.

### 4.2 OOS (один прогон выбранного варианта)

| # | Гейт | Порог |
|---|---|---|
| O1 | Сделок | **≥ 30** |
| O2 | Profit Factor | **≥ 1,30** |
| O3 | P(noEdge) | **< 0,05** |
| O4 | CI95 среднего net | **не содержит 0** |
| O5 | Max Drawdown | **≤ 40 %** (от 100k) |

PASS = все O1–O5; REJECTED = O2 или O5; INCONCLUSIVE — иначе.
PASS = реализовать в движке и formal WFA, не LIVE.

## 5. Анти-подбор

1. Окна (5 дней до конца, 2+2 turn-of-month, пятница) фиксированы.
2. OOS 2022–2024 запускается один раз.
3. Отрицательный результат закрывает календарный класс на этих данных.
4. Новые окна/дни на том же OOS запрещены.

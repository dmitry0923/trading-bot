# Предрегистрация: портфель momentum+low-vol на 5 фьючерсах (2026-11-02)

**Статус:** зафиксировано **ДО** прогона. После чисел параметры не меняются.

**Зачем:** лучший CNYRUBF-кандидат — `mom20_5` + low-vol (`docs/41`):
52 сделки, PF **1,79**, avg **+53,69 ₽**, но p=0,060. Блокер — **мощность
выборки**, а не знак edge. Расширение той же гипотезы на 5 ликвидных
фьючерсов (CNYRUBF, USDRUBF, EURRUBF, GLDRUBF, IMOEXF) даёт в 3–5 раз больше
сделок. Проверяется, является ли momentum+low-vol **общим** эффектом, а не
случайностью CNYRUBF.

> Pre-screen вне движка; PASS — только повод реализовать в движке и прогнать
> formal WFA. Для LIVE потребуется решение по allowlist (сейчас CNYRUBF-only).

Издержки: комиссия 1,5 ₽/контракт/сторона; slippage 1,0 bp/сторона; funding

**Разделение:** Dev = 2024-10-24…2026-10-30; OOS = 2022-12-05…2024-10-23
(новый горизонт, не использованный ранее).

## 2. Сигнал (тот же, что V1 `docs/41`)

- `mom = close(D)/close(D−20) − 1`; направление `sign(mom)`.
- `ATR20% = ATR20/close`; `volPct` — перцентиль за 252 дня.
- Торгуем только при `volPct ≤ 0,50` (low-vol).
- Вход на открытии `D+1`; выход через 5 дней; одна позиция на инструмент,
  без пирамидинга. Если сигнал во время удержания — игнорируется.

**Портфель:** все инструменты торгуются независимо; P&L суммируется по датам
выхода. Один контракт на инструмент.

## 3. Статистика (важно: корреляция)

Из-за кросс-инструментной корреляции наивный bootstrap по сделкам занижает
p-value. Используется **блочный bootstrap по датам выхода**: блок = все
сделки, закрывшиеся в этот день (по всем инструментам); блоки
ресемплируются с возвращением (2 000 итераций, seed 42); p = доля
бутстрэп-средних ≤ 0. Дополнительно — наивный p для сравнения.

## 4. Гейты

### 4.1 Dev (портфель)

| # | Гейт | Порог |
|---|---|---|
| D1 | Сделок | **≥ 100** |
| D2 | Profit Factor | **≥ 1,30** |
| D3 | Блочный P(noEdge) | **< 0,05** |
| D4 | Средний net | **> 0** |

Если D1–D4 пройдены — OOS-прогон портфеля один раз. Если нет — класс
закрывается `REJECTED`, OOS не запускается.

### 4.2 OOS (портфель)

| # | Гейт | Порог |
|---|---|---|
| O1 | Сделок | **≥ 30** |
| O2 | Profit Factor | **≥ 1,30** |
| O3 | Блочный P(noEdge) | **< 0,05** |
| O4 | CI95 блочного среднего | **не содержит 0** |
| O5 | Max Drawdown | **≤ 40 %** (от 100k) |

PASS = все O1–O5; REJECTED = O2 или O5; INCONCLUSIVE — иначе.

## 5. Анти-подбор

1. Юниверс (5 инструментов), low-vol ≤ 0,50, hold 5, momentum 20 — фиксированы.
2. OOS 2022–2024 запускается один раз.
3. Отрицательный результат закрывает класс «momentum+low-vol portfolio».
4. Добавление новых инструментов/порогов на том же OOS запрещено.

O1 ✅ (161 ≥ 30), O2 ✅ (PF 1,384 ≥ 1,30), O5 ✅ (MDD 23,46 % ≤ 40 %),

`INCONCLUSIVE`, не PASS.

**Что это значит:**

1. **Первый кандидат, который прошёл dev и OOS по PF/MDD/сделкам.**
   Dev PF 1,78 (block p=0,0135), OOS PF 1,38 на 161 сделке — это не
   «режимный бет» на 12 сделках, а широкий портфель из 5 инструментов.
2. **Edge экономически достаточен для 100 %:** OOS avg **+191,69 ₽/сделку**
   при 1 контракте на инструмент. При `maxC 3–4` и 160–240 сделках это
   кратно больше требуемых 25–67 ₽; вопрос только в статистической
   значимости и в том, сохранится ли edge вперёд.
3. **Блокер — мощность OOS-теста, а не знак edge:** 161 сделка, block
   p=0,0875, CI95 [−94; +445] содержит 0. Для p<0,05 нужна выборка в ~2
   раза больше или независимый горизонт.
4. **OOS 2022–2024 для этой гипотезы израсходован.** Повторный прогон с
   другими порогами/инструментами на нём запрещён. Следующий шаг — новый
   независимый горизонт (акции 2018+ или другой класс активов), а не
   донастройка на этом OOS.

**Оговорка:** 1 контракт на инструмент — не риск-паритет; P&L портфеля
взвешен по нотионалам (USDRUBF доминирует). Для live-аллокации нужен
risk-parity/ATR-сайзинг; это отдельный шаг, не влияющий на знак edge.

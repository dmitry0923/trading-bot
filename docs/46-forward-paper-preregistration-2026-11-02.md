# Предрегистрация: forward paper momentum+low-vol на 5 фьючерсах (B, 2026-11-02)

**Статус:** зафиксировано **ДО** старта forward-сбора. Параметры не меняются
до вердикта.

**Зачем:** fixed-split engine-валидация (`docs/45`) дала **REJECTED** по dev
D3, но post-hoc WFA folds=3 — **PF 3,01, block p=0,002** на 75 OOS-сделках.
Расхождение можно разрешить только **новыми данными**. B — forward paper-
портфель: те же правила, но сделки фиксируются вперёд, без live-ордеров.

## 1. Правила (заморожены)

- Юниверс: **CNYRUBF, USDRUBF, EURRUBF, GLDRUBF, IMOEXF**.
- Сигнал на закрытии завершённого дня `D`:
  `mom = close(D)/close(D−20) − 1`; `ATR20%`; `volPct` за 252 дня;
  торгуем только при `volPct ≤ 0,50`; направление `sign(mom)`.
- Вход — по открытию следующего торгового дня `D+1`; выход — по закрытию
  через 4 бара после входа (5 баров включая вход). Одна позиция на инструмент,
  без пирамидинга; сигналы во время удержания игнорируются.
- Размер: **1 контракт на инструмент**; издержки: комиссия 1,5 ₽/сторона,
  slippage 1 bp, funding по фактическому `funding_history` за клиринги.
- Капитал для нормировки риска: **100 000 ₽** (`paperCapitalRub`). Это не сайзинг
  и не изменение правил, а знаменатель зарегистрированного гейта F5.
- Live-ордера **не выставляются**; LIVE-контур не меняется (`maxC=1`,
  Kelly, allowlist CNYRUBF).

## 2. Старт и данные

- Старт: первый торговый день после **2026-11-03** (2026-11-04 — праздник,
  поэтому фактически 2026-11-05). Источник — `candles` DAY_1.
- **Cutoff без look-ahead:** ежедневный запуск — после закрытия (≥ 23:50 МСК);
  по умолчанию `AsOf` = сегодня, если запуск после 23:50, иначе вчера.
  Используются только бары с `time <= AsOf`; явный `-AsOf` = сегодня до
  закрытия отклоняется (бар неполный).
- **`-Init` только инициализирует состояние:** `lastProcessedDate` =
  max(`StartAfter`, последний завершённый бар), `position`/`pending` пусты,
  исторические сделки не создаются. Без `-Init` при отсутствии state скрипт
  падает, а не начинает с исторического бэкфилла.
- Состояние: `artifacts/paper_momentum/state.json` (schema v1: `startAfter`,
  `params` включая `paperCapitalRub`, `tickers.{lastProcessedDate,position,pending}`, `trades`); журнал —
  `artifacts/paper_momentum/trades.csv`; сводка — `summary.json`.
- **Параметры заморожены:** state хранит `params`; несовпадение с аргументами
  запуска (юниверс, 20/20/252/0,50/hold 5, издержки) → ошибка, а не тихое
  применение новых настроек.
- **Пропущенные дни:** скрипт обрабатывает все завершённые бары после
  `lastProcessedDate` по порядку (catch-up) без изменения правил; `recordedAt`
  в сделке показывает, когда она фактически записана. Ежедневный запуск —
  обязательный режим, catch-up не заменяет forward-наблюдение.
- **Funding fail-closed:** для каждого торгового дня удержания нужна строка
  `funding_history`; если её нет, скрипт останавливается, позицию не закрывает
  и просит донакачать ряд (повторный запуск после донакачки идемпотентен).
- Ежедневный запуск: `scripts/paper_momentum_daily.ps1` после закрытия
  (23:55 МСК) или вручную.

## 3. Гейты (оценка после ≥ 30 закрытых forward-сделок)

| # | Гейт | Порог |
|---|---|---|
| F1 | Закрытых сделок | **≥ 30** |
| F2 | Profit Factor | **≥ 1,30** |
| F3 | Блочный P(noEdge) по датам выхода (2 000, seed 42) | **< 0,05** |
| F4 | CI95 блочного среднего | **не содержит 0** |
| F5 | Max Drawdown | **≤ 40 %** от `paperCapitalRub=100k`; дневная closed-trade equity по датам выхода |

Дополнительно: оценка в контрольных точках 30 и 60 сделок; параметры не
меняются; при F2/F5 fail — кандидат закрывается; при F3/F4 fail —
INCONCLUSIVE, продолжается сбор до 60 сделок (без изменения правил).
Гейты и вердикт автоматически пишутся в `summary.json` после каждого запуска
(до 30 сделок — `COLLECTING`, `evaluated=false`). `stats.mddRub` хранит абсолютную
просадку, `stats.mddPct` — `100 × mddRub / paperCapitalRub`. Сделки одного дня сначала
суммируются, поэтому результат не зависит от их порядка. Это просадка по закрытым
сделкам, а не mark-to-market просадка с открытыми позициями.

## 6. Валидация раннера

Исторический dry-run на отдельном `StateDir` (не production-состояние):

```powershell
.\scripts\paper_momentum_daily.ps1 -Init -Force -StartAfter 2024-09-01 `
  -AsOf 2024-09-01 -StateDir artifacts/paper_momentum_test
.\scripts\paper_momentum_daily.ps1 -StartAfter 2024-09-01 -AsOf 2024-11-29 `
  -StateDir artifacts/paper_momentum_test
```

33 закрытые сделки **совпали с pre-screen** (`docs/42`) один-в-один по
направлению, датам входа/выхода и net (±0,02 ₽); повторный запуск не создал
дубликатов (33 → 33). Это проверяет сигнал, удержание 5 баров, издержки и
funding, но не является forward-результатом. После проверки тестовый
`StateDir` удаляется; production-состояние инициализировано с 0 сделок.

**Расширенный dry-run 2024-10-24…2026-10-19** (тот же state machine, temp
state, `AsOf=2026-10-19`): **232 закрытые сделки + 5 открытых**, PF **1,644**,
avg +197,45 ₽, block p=**0,0225**, CI95 low +4,61 ₽, MDD 13,71 %; F1–F5 PASS.
Pre-screen dev (`docs/42`) — 241 сделка, PF 1,781, p=0,0135. Совпадение по
числу/качеству подтверждает parity; это **in-sample** проверка, не forward.

**Исправлен дефект:** `funding_history` не содержит выходных, а MOEX DAY_1-
бар в выходные может быть (weekend session). Раннер считал выходной
клирингом и fail-closed останавливался на GLDRUBF 2025-08-16/17. Теперь
клиринг — только будни; отсутствие funding в **будний** день по-прежнему
fail-closed.

- **Старт forward-окна:** 2026-11-05 (2026-11-04 праздник). До этой даты
  запуски — no-op. Первый сигнал — после закрытия 2026-11-05, вход — на
  следующем торговом дне (≈2026-11-06), первый выход — через 5 баров

- **Что проверять:** `artifacts/paper_momentum/summary.json` — `closedTrades`,
